RFSoC4x2 分光計 · proj015 rev3 · win_core_i（4 ADC × 4 窓）の中身

窓の 3 段: pfb_core → ddc_core → wspec_core

ADC ごとの 4096 MSPS の実数列から、幅 W（256〜2 MHz の 8 通り）の窓を 4 つ切り出し、それぞれ 4096 ch の電力スペクトルにする。粗い PFB は ADC ごとに 1 つを 4 窓で共有し、NCO・半帯域・FFT・積分は窓ごと。win_core_i（i = ADC_A..D）が 4 つあり、16 窓が同時に動く。3 段とも DSP ドメイン 256 MHz で動き、固定小数点の模型（model/win_fixed.py）と bit 単位で一致することを sim で確かめてある。

窓の置き方（PS が決める 3 つの値）

ゾーン 2 なので、IF と ADC の見かけの周波数 f は f = 4096 − IF（MHz）。窓の中心 c（f の側）を粗い ch と端数に分ける。

WK = round(c / 128) 粗い ch（0..16）。pfb_core の k d = c − 128·WK 端数（|d| ≦ 64 MHz） WDPHI = round(d / 512 · 2^32) mod 2^32 NCO の 1 サンプルの位相の増分（512 MSPS で） WNS = 1..8 半帯域の段数 → W = 512 / 2^WNS MHz（7・8 = 4・2 MHz は proj015）

3 つとも窓ごとのレジスタ（窓 w は 0x20000·w から）に書き、CTRL[12] = WRST で取り込んで、その窓の 3 段だけを最初からやり直す（フレーム番号・積分も 0 から。ほかの窓は止まらない）。観測中は変えない前提。PS の既定は中心を ch の格子に丸め、k·fs/8 の線（IF 2560・3072・3584 MHz）が窓の中央 90 % に入ると警告する。

pfb_core粗い PFB・4 窓で共有

4096 MSPS の実数列を 32 本の多相フィルタバンクに通し、窓 w ごとに ch k_w（中心 f = 128k_w MHz）の 1 本を 512 MSPS の複素数列 y として出す。分岐の和と 16 点 DFT は ADC ごとに 1 つ（共有）、ch の選択・実数化・(−j)km・丸めは窓ごと。ch 間隔 128 MHz に対して出力が 512 MSPS なので 4 倍オーバーサンプリングになり、±64 MHz の端数 d と窓の幅の半分を足しても ch の通過域に収まる。

y_k[m] = Σ_n h[n] · x[p − n] · exp(−j2πk(p − n)/32) p = 8m + 95、N = 96 タップ

段の中身

  1. 分岐の和: u_r[m] = Σ_t h[r+32t]·x[p−r−32t]（r = 0..31、t = 0..2）→ Q10 に丸め・22 bit で飽和
  2. 32 点の実 DFT の 1 ch: 偶奇を複素に詰めて 16 点 DFT（dft16f）→ 実数化の後処理（−j·W32k）
  3. (−j)k·m を掛ける（位相の m で変わる部分。定数の位相は電力に効かないので落とす）
  4. Q8 に丸め・24 bit で飽和 → y

振る舞いの約束

  • 1 ビート（16 サンプル）で 2 フレーム出す（ホップ 8 サンプル）。窓は直近 7 ビート = 112 サンプル
  • tvalid が落ちたビートでは窓を進めない。途切れても値は入力の列だけで決まる
  • 窓ごとの始まり: 窓 w は w_rst を下ろした後の最初の valid なビート q_s（q ≧ 5）から数え、m′ = m − m_s（m_s = 2q_s − 10）≧ 0 のフレームだけ y_ok = 1。窓 w の出力は模型に x[8·m_s:] を与えたものと bit 単位で同じ。q_s は WSTART（0x8C）に出る
  • ok と m′ の偶奇は飽和する数えで作る（proj014 は 32 bit の q との比べで、16.8 秒ごとの巻き戻りで 6 ビート ok が落ちていた。proj015 で直した）
  • k は動作中に変えない（変えたらその窓だけ WRST）
  • DSP: 分岐の和 192 ＋ dft16f 64（共有）＋ 実数化 8 × 4 窓 = 288。分岐の和は対称の相手が別の分岐にあるので前置加算が使えない
  • rev2: 16:1 の ch の選択の後と B の後にレジスタ（遅延 18 → 20 クロック、値は同じ）

ddc_coreNCO と半帯域の縦続

y に NCO を掛けて窓の中心を 0 Hz に寄せ、半帯域フィルタで 2 分の 1 ずつ落として幅 W の複素数列 z にする。段数 WNS で 8 通りの幅を 1 本の bit で切り替える。

v[m] = round( y[m] · (cos φ − j sin φ) / 2^17 ) φ = 2π(a + 1/2) / 2^14, a = (m·WDPHI mod 2^32) の上位 14 bit z = sat18( round( v / 2^(8 − G) ) ) G = 4（WNS ≦ 6・Q4）/ 5（WNS 7・8・Q5）

NCO

  • 位相の累算 32 bit。1/4 波の表 4096 語 × 18 bit（振幅 217 − 1）を 2 口 ROM × 2 で引く
  • 番地に半 LSB のずらし（a + ½）を入れて、表の端の重複と偏りを消す
  • m = 0 は pfb_core の最初の ok なフレームで、そこで位相 0
  • pfb の出力の並び（y0 = 奇 m、y1 = 偶 m）を組（偶, 奇）に詰め直して 2 サンプル / 組で進む

半帯域（hb2・hb2s）

  • 0 でない係数は偶数番目と中心だけ。対称なので前置加算で乗算は L + 1 個 / 成分
  • 組の間隔は自由（入力が来たときだけ進む）。遅延 5 クロック
  • 軽い段（15 タップ）を WNS − 1 段（最大 7 段）→ 最後に鋭い段（67 タップ）を 1 段。係数は proj014 と同じ（4・2 MHz も段を足すだけ）
  • 時分割（hb2s）: 軽い段の j 段目（j ≧ 2）には組が 2j−1 クロックに 1 回以下しか来ないので、乗算を C = min(2j−1, L + 1) クロック使い回す（値は hb2 と bit 単位で同じ）。前提が破れたら DDC_OVR（0x88）を数える。DSP は窓 1 つ 114 → 72（NCO 8・light 1 段目 10・2 段目 6・3 段目 4・4〜7 段目 2 ずつ・final 36）
  • rev2: hb2 の和を 2 項ずつの木にした（1 段ごとにレジスタ。値は同じ）
  • 各段 Q8 で丸め・24 bit で飽和。飽和は数えて DDC_SAT に出す

wspec_core溜め・FFT・電力・積分

z を 4096 語ずつ溜めて、溜まった面を途切れなく FFT IP に流し、電力を 64 bit で積む。realtime の FFT IP は入力の途切れを待たないので、W MSPS で必ず途切れる z を直接はつなげない。溜めがそのための緩衝になる。

Y = FFT4096(z) 順変換・unscaled（31 bit）・自然順 q = sat18( Y >>> SHIFT ) p = q_re² + q_im² 37 bit S = Σ p （N_ACC フレーム） 64 bit・二面

溜めと FFT への流し込み

  • 2 面 × 4096 語。書きながら、溜まった面を 4096 クロックで読み出す
  • 出口のレジスタは「空いている か IP が受けた」ときだけ進む（AXI の握手、proj014 rev2 から）。待たされても 1 語も落とさず、IP の枠 = 溜めの枠が保たれる
  • 読み出しが遅れたら次の面は予約して遅れて始める。書き込みが未読の番地に追いついたときだけ FLAGS[1]

積分と読み出し

  • RUN の時点で F0 = fin + 2（確実に未来）。ダンプ k はフレーム F0 + k·N … + N − 1
  • ダンプが閉じるたびに SEQ が 1 増え、読み出しの面が切り替わる（PS は SEQ → 中身 → SEQ で読む）
  • ダンプ k の最初のフレームの z を 4096 語スナップショットに残す（ADC で 1 つを共有し、SNAP_SEL の窓だけが書く）。N_ACC = 1 なら FFT(スナップショット) とダンプが 1 対 1（--golden、SHIFT 7 で比べる）
  • 既定 N_ACC = 6250（W = 256 MHz で 100 ms）。rev3: SHIFT を窓の中で受け直す（値は同じ・1 クロック遅れて効く）

win_core_i の共通ADC ごとに 1 つ

4 窓のほか、ADC ごとに 1 つずつ持つもの。AXI4-Lite は 1 MiB（20 bit 番地）で、窓 w は 0x20000·w、共通は 0x80000 から。

ADC の共通

  • total power（tp_core）: Σx²・1 ms・リング 512 個（0x82000〜）。4 ADC すべてで測る（DSP 24）
  • ギアボックスの制御: gb_hold・gb_adj・gb_k（GB_K）・gb_dn_rstn を ch ごとに握る。見張りは GB_STAT・ADC_STAT
  • FULL_SEL: win_core_0 のものだけが効き、全帯域の spec_core_0 につなぐ ADC を選ぶ（W-6・W-1b の基準）
  • SNAP_SEL・ID（0x0015_A300）・NW = 4

読み出し

  • 応答は ar を受けてから 5 クロック後（rev3: 候補を 1 段のレジスタで受けてから選ぶ。値は同じ）
  • LO を読むと HI を固定（FIN・FOUT・TFIN）。rev3 は固定を ar の 1 クロック後に
  • 実機: 1 ダンプ（4096 ch × 64 bit）の読み出し 2.14 ms、16 窓で 34.2 ms / 100 ms（W-11）
  • 窓ごとに 0x88 DDC_OVR・0x8C WSTART・0x90 WIDX（proj015）

資源（rev3、win_core 1 つ）: DSP 728 = pfb 288 ＋ (ddc 72 ＋ ws 32) × 4 ＋ tp 24。4 つで 2912、spec_core_0 504 と合わせて 3416（80 %）。-1 で WNS 0.000 ns。
