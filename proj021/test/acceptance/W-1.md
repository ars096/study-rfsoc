# W-1 — SG の CW が予言の ch に出る・周波数の差

- **前提**: 共通の前提。ボード直（root、specd を止めてから）。**配線 S**（SG だけ）。SG は外部 10 MHz に同期
- **手順**:

```bash
python3 window.py --clkin 0 --ref 10 --tone 3010.5 --w 256 --sg $SG --sg-dbm -0.9
python3 window.py --clkin 0 --ref 10 --tone 3010.5 --w 64 --sg $SG --sg-dbm -0.9
```

- **合格**（測る前に決めた条件）:
  - 道具の W-1 が OK（山の ch = 予言の ch。W 256 は 3928）
  - 推定した IF と SG の周波数の差 |·| ≦ 0.5 ppm（**新しく決めた値**。2-2a・2-2d では +0.10 ppm で、数を見るだけだった）
  - ADC の飽和 0
- **陽性対照**: なし（ch がずれれば道具の W-1 が NG）
- **記録**: **最終の bit で未**。2-2d までは `--w6` と一緒に回していた（W-1 ch 3928・+0.10 ppm、配線は ノイズソース ＋ SG +20 dBm）
