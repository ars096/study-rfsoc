# P-5 — ch の応答（半 ch −3 dB・−3 dB 幅 1 ch）

- **前提**: 共通の前提。specd（ボードで `python3 specd.py --clkin 0 --ref 10 --bits bits.json`、制御 PC から）。**配線 S**（SG だけ。ノイズソースは外す）
- **手順**:

```bash
python3 s45resp.py --host $B --sg $SG --dbm -0.9 --span 0 --kch 1 --nsub 32 --out resp_xxx
```

- **合格**（測る前に決めた条件）:
  - ADC で ≒ −20 dBFS（± 3 dB）、飽和 0
  - 8 窓とも **半 ch −3.00 ± 0.01 dB**・**−3 dB 幅 1.000 ± 0.002 ch**
  - ref（ch の中心の利得）0.9913〜0.9916
- **陽性対照**: 参考: PFB の無い窓（proj017）では半 ch −3.9 dB（sinc²）になる。測りが PFB の有無を見分ける
- **記録**: proj021 README「配線の要る判定 → P-5 の結果」（2026-10-14 通過、`resp_p25`: 半 ch −2.999〜−3.001 dB・幅 0.9997〜0.9999 ch）
