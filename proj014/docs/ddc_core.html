ddc_core：粗い ch から窓を切り出す

pfb_core が出す粗い ch k（複素 512 MSPS）を、NCO で窓の中心 d だけ下げて 0 に寄せ、半帯域フィルタで ÷2 を NS 回くり返して、 幅 W = 512 / 2NS MHz（256〜8 MHz）の複素 W MSPS にする。出口の z は 18 bit で wspec_core の 4096 点 FFT に入る。

仕様の式

model/win_fixed.py の ddc_fixed と bit 単位で同じ。m は pfb_core のフレームの番号で、m = 0（最初の ok なフレーム）で NCO の位相が 0。

① NCO（窓の中心 d を 0 へ） v[m] = round( y[m] · (cos φm − j sin φm) / 217 ) 24 bit・Q8（y と同じ小数部） φm = 2π (am + 1/2) / 214 am = (m·Δ mod 232) の上位 14 bit Δ = round(d / 512 · 232) 1 フレームあたりの位相の進み（512 MSPS で d MHz） ② 半帯域で ÷2（hb2。N = 4L − 1。0 でない係数は偶数番目と中心だけ） y[q] = Σj=0..N−1 h[j] · x[2q + j] = Σi=0..2L−1 h[2i] · e[q + i] + h[2L − 1] · o[q + L − 1] e[n] = x[2n]、o[n] = x[2n + 1] 対称 h[2i] = h[2(2L − 1 − i)] → 前置加算で、乗算は成分あたり L + 1 個 ③ 縦続（NS = 1..6） light × (NS − 1) → final × 1 W = 512 / 2NS MHz light: L = 4（N = 15）、final: L = 17（N = 67） ④ 出口 z = sat18( round( v' / 24 ) ) v' = final の出力（Q8）→ z は Q4（G = 4）

組にまとめ直す（タイミング）

pfb_core は 1 ビートに（y0 = 奇 m、y1 = 偶 m）を出すが、後ろは（偶 m, 奇 m）の組で進めたい。そこで y1 を保持しておき、次の valid なビートの y0 と組にする。 最初の組は y1 の m = 0（q = 5）と y0 の m = 1（q = 6）で、ここで NCO の acc = 0 から始まる。途切れ（下の例のクロック 6）をまたいでも組はずれない。

段ごとの間隔（タイミング、NS = 1〜6）

light の 5 段は NS によらずいつも動いていて、NS は final の入力（pa[NS − 1]）を選ぶだけ。なので上の 11 本（pa と light の出力）は全 NS で共通で、 違うのは下の z_valid だけになる。hb2 は組を 1 つ受けるたびに 1 サンプルを出し（÷2）、pair2 が 2 サンプルを組にするので、段を進むたびに strobe の間隔が倍になる。 どの段も in_v が来たときだけ履歴を進めるので、間隔が一定でなくても値は変わらない。

NCO の中身

表の引き方

  • 番地 a（14 bit）の上位 2 bit が象限、下位 12 bit が r
  • 表は T[r] = round(131071 · sin(2π(r + 1/2) / 214))、r = 0..4095
  • 2 口で T[r] と T[4095 − r] を同時に引き、象限で入れ替えと符号を決める
  • 半番地ずらし（+1/2）なので sin = 0 の番地がなく、4 象限が完全に対称

周波数と位相

  • Δ は 32 bit。周波数の刻みは 512 / 232 MHz ≒ 0.12 Hz
  • 表を引くのは上位 14 bit。位相の切り捨てのスプリアスの見当は −6.02 × 14 ≒ −84 dBc
  • d = ±64（粗い ch の境目）は Δ = ±229 で、番地の下位がいつも 0
  • 偶と奇で表を 1 組ずつ持つ（2 組 × 2 口）。1 組 / クロックで回せる

半帯域の縦続の応答

出口のレートは W なので、窓の中心から ν の成分には ν ± W, ± 2W … が折り返してくる。使うのは中央 90 %（|ν| ≦ 0.45W）なので、 そこへ落ちる 0.55W〜1.45W を final で落とす。light の各段は、自分の入力レートの 0.1125 倍まで平らで（0.0017 dB p-p）、0.3875 倍より外を 80 dB 落とす。 その外（粗い ch の外）は pfb_core の阻止域の受け持ち。

振る舞いの約束

途切れと起動

  • 組・NCO・hb2・pair2 はどれも valid が来たときだけ進む。入力の間隔が変わっても値は変わらない
  • 最初の組は hv（y1_ok）と y0_ok がそろったときで、m = 0 で位相 0
  • hb2 の最初の出力は 2L − 1 組目（light は 8 組目、final は 34 組目）。それより前は出さない
  • pair2 は rst の後の最初のサンプルを偶とする

設定

  • dphi・ns は RUN 中は変えない。win_core の WRST で取り込んで rst を打つ
  • ns が 1..6 の外なら NS = 1 と同じ（sel = 0）
  • NS を変えても light の 5 段は動いたまま。final の入力の切り替えだけ

丸めと飽和

  • 丸めはどこも +2SH−1 してから >>> SH（端数 0.5 は +∞ 側へ）
  • sat_cnt は NCO の出口・使っている light の段・final・z の飽和を数え、0xFFFF で止まる
  • win_core の 0x70 DDC_SAT で読む。W-0 はこれが 0 であること

hb2.v の冒頭の注記は「レイテンシ 5」だが、部分和の段（v3b）を足した後のレジスタは 6 段（in_v → v1 → v2 → v3 → v3b → v4 → out_v）。この図は 6 で描いた。値と照合には効かない（valid で運ぶので）。

確かめ方

sim（make sim-ddc）

  • iverilog で RTL と ddc_fixed を bit 単位で照合。出力の数も模型と同じこと、飽和 0
  • NS = 1..6 × d = 64（境目、Δ = 229）/ −37.81234567（格子の外、位相の下位 bit まで使う）× 入力の途切れ あり / なし
  • 入力は pfb_fixed の出口（雑音・CW 2 本・飽和ぎりぎりの区間）
  • 陽性対照 SIM_DDC_POSCTL=1：偶の側の NCO の番地を 1 つずらすと落ちる。模型の陽性対照 hb-short・nco-sign も落ちる

実機（rev2）

  • W-1：CW の ch の位置が予言どおり（ボードと SG を同じ 10 MHz に載せて）。W-1b：窓と全帯域の推定 IF の差 +2.2 kHz（読みの床）
  • W-2：窓の中の平らさが模型と 0.015 dB 以内。W-3：折り返し −61 dB 前後で模型どおり
  • W-7：線形性 0.011 / 0.005 dB（256 / 8 MHz）。W-8：WRST を 150 回くり返して全部通過
