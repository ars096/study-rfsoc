## 最終仕様（2026-09-18 に決定）

| | 値 |
|---|---|
| IF 入力 | **2〜4 GHz**（45m から来る IF のまま。アナログで下げない）|
| IF 入力数 | **4**（ADC_A/B/C/D 同時）|
| 窓 | **1 IF あたり最低 2、目標 4、最高 8**。窓の位置と幅は任意（例: 2.1〜2.2 / 3.0〜3.2 / 3.5〜3.55 GHz）|
| 構成 | ADC → **PL 内で分配** → 窓ごとのフィルタ → FFT → 積分 |
| fs | **4096.0 MSPS** |

### なぜハード DDC ではないか

RFDC のハード DDC は **ADC 1 本につき 1 系統**しかない。1 本の IF から複数の窓を取るには、
**間引きなしで全レートを PL に入れ、PL 内で分配する**しかない。

### なぜ 4096 MSPS か

2〜4 GHz（幅 2 GHz）を実数サンプリングで 1 つのナイキストゾーンに収めるには **fs = 4.0 GSPS ちょうど**しかなく、
それでもガードバンドはゼロになる。**どの fs を選んでも帯域の端は 100 MHz 前後削れる**ので、
「4.0 に近くて作れるもの」から選んだ。

RFDC タイル内 PLL の範囲（PG269: R 1〜4 / N 13〜160 / M 2, 3, 4, 6, 8…偶数 ≤64 / VCO 8.5〜13.2 GHz）と
LMX の 491.52 MHz から、4 GSPS 付近で作れるのは次の 4 つ。**M = 2 では VCO 下限から fs ≥ 4.25 GSPS になるので M = 3 を使う。**

| fs (MSPS) | R | N | M | VCO (MHz) | AXIS（16 サンプル/ビート）| 無事に使える帯域 |
|---|---|---|---|---|---|---|
| 3932.16 | 1 | 24 | 3 | 11796.48 | 245.76 MHz | 2.00〜3.86 GHz |
| 4014.08 | 2 | 49 | 3 | 12042.24 | 250.88 MHz | 両端とも余裕が無い |
| 4055.04 | 4 | 99 | 3 | 12165.12 | 253.44 MHz | R = 4 で位相雑音に不利 |
| **4096.0** | **1** | **25** | **3** | **12288.0** | **256.0 MHz** | **2.10〜4.00 GHz** |

**決定: 4096.0 MSPS（R = 1 / N = 25 / M = 3）。**
理由: R = 1 で LMX の 491.52 MHz をそのまま使える（proj004 の 10 MHz 系統は無変更）。上側に 96 MHz の余裕がある。
1 秒 = 256,000,000 ビートちょうど。AXIS 256 MHz は 4915.2 MSPS（307.2 MHz）より 2 割軽い。
見送った案: 3932.16（下端 2.0 GHz から使えるが 3.86 GHz より上を失う）／ 4.000 ちょうど（491.52 からは作れず、
LMX を分数分周にするとスプリアスを抱える。作れてもガードバンドはゼロ）／ 4915.2（2〜4 GHz がゾーン 1 と 2 にまたがり、
2.0〜2.46 と 2.46〜2.92 GHz が重なる）。
**代償**: 2.0〜2.05 GHz の成分が 2.05〜2.10 GHz に折り返す。**ADC 前の BPF は下端を急峻に切る必要がある。**

### 周波数計画（fs = 4096 MSPS）

```
ゾーン 1: 0      〜 2048 MHz   (f_obs = f)
ゾーン 2: 2048   〜 4096 MHz   (f_obs = 4096 − f)   ← IF 2〜4 GHz はここ。スペクトルは反転する
ゾーン 3: 4096   〜 6144 MHz   (f_obs = f − 4096)
```

- **ゾーン 2 はスペクトルが反転する。** 周波数軸の向きを取り違えると、線の位置は合っていても左右が逆になる
- RFDC は `NyquistZone = 2` に設定する（較正をゾーン 2 に合わせる）

## 今回の構成から変わるもの

| | proj003〜008 | proj009 |
|---|---|---|
| fs | 1228.8 MSPS | **4096.0 MSPS** |
| タイル PLL | N = 20 / M = 8 | **N = 25 / M = 3** |
| AXIS | 8 サンプル × 16 bit = 128 bit / 153.6 MHz | **16 サンプル × 16 bit = 256 bit / 256.0 MHz** |
| 1ch のデータレート | 2.4576 GB/s（DMA で連続取得）| **8.192 GB/s（DMA では連続で流せない）**|
| 取得 | FIFO → DMA | **BRAM に一定長ためてから読み出す** |
| ナイキストゾーン | 1 | **2** |
| 時刻層 | `L_adc`・`MAGIC`・153,600,000 ビート/s | **作り直し**（256,000,000 ビート/s）。**proj009 の範囲外** |

変わらないもの: LMX 491.52 MHz、LMK と外部 10 MHz 基準（proj004）、SMA ↔ タイル/スライスの対応とタイル間 180°（proj006）。

## 成功の判定

**まず 1ch（ADC_B = Tile 226 / slice 0）で通す。** 4ch（1024 bit / 256 MHz）はその後。

キャプチャ長 65536 サンプル（16 µs）で **FFT 分解能 = 4096 MHz / 65536 = 62.5 kHz ちょうど**。
試験トーンは 62.5 kHz の倍数に置いてビン中心に立てる。

| | 判定 |
|---|---|
| 1 | IP から読み返した fs・R/N/M が設計値どおり。実機で `PLLLockStatus = 2`、`SamplingFreq = 4.096` |
| 2 | **予言**: ゾーン 2 のトーン（例: 2.2 / 3.0 / 3.9 GHz）が **4096 − f**（1896 / 1096 / 196 MHz）に、期待する電力で立つ |
| 3 | **予言**: SG の 2 次高調波が計算どおりの位置に出る（例: 3.0 GHz の 2 倍 6.0 GHz → ゾーン 3 で 1904 MHz）。**置き場所を先に書いてから測る** |
| 4 | **16 並列の並び順が正しい**: 並びを誤ると k·fs/16 ± f にスプリアスが立つ。**それらしいスペクトルは出てしまうので、トーンの純度で判定する** |
| 5 | 外部 10 MHz ロックが維持されている（トーン周波数のずれで proj004 と同様に確認）|
| 6 | 256 MHz で WNS ≥ 0、CRITICAL WARNING なし |

**判定 4 を外さないこと。** 並び順の誤りも「動いているように見える失敗」になる。

### 最大の未知数: spw = 16 が IP に通るか

**1 語 16 サンプルを RFDC IP が許すかは確かめていない。**許すのが 8 までなら AXIS は 512 MHz になり、
PL では閉じない。12 なら 341.33 MHz で重いうえに **1 秒が整数ビートにならない**（時刻層の前提が崩れる）。
その場合は fs の選び直し（例: 3932.16 MSPS / 12 = 327.68 MHz）まで戻る可能性がある。
**だから `make` の前に `make probe` を通す。**合成に入らないので数分で終わる。
