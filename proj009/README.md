## 目的

**分光計そのものを作る。** proj001〜008 は土台で、**ここが実証試験の本体である。**

| | |
|---|---|
| proj001〜002 | ツールチェーンと PYNQ オーバーレイ |
| proj003〜005 | ADC の生データと評価 |
| proj006 | 4ch 同時取得 |
| proj007〜008 | 時刻（1PPS・エポック・較正） |
| **proj009** | **チャネル化と積分** ← ここ |

proj007 は**積分窓の生成を意図的に見送った**。理由は「窓の生成は FFT と積分器の構造
（何ビン・何段・オーバーフローの扱い）に結合するので、先に窓だけ作ると必ず作り直しになる」。
**その構造を決めるのが proj009 である。**

### 1. 帯域・チャンネル数・積分時間 —— **ここから全部が決まる**

runbook: 「ここから PFB の分岐数、FFT 長、積分器のビット幅と BRAM 量が**一意に決まる**。
逆に決まっていないとブロック構成を選べない。」

**今の構成から決まっている制約:**

| | |
|---|---|
| fs | **1228.8 MSPS**（外部 10 MHz にロック済み）|
| **1ch あたりの帯域** | **614.4 MHz**（第 1 ナイキスト）|
| ch 数 | **4**（ADC_A/B/C/D。proj008 で較正器を置かないと決めた）|
| 分解能 | **1228.8 MHz ÷ FFT 長** |

| FFT 長 | 分解能 | ch 数/入力 | ダンプ量（4ch・32 bit）| 1 kHz での帯域 |
|---|---|---|---|---|
| 1024 | 1.2 MHz | 512 | 8 kB | 8 MB/s |
| 4096 | 300 kHz | 2048 | 32 kB | 32 MB/s |
| 8192 | 150 kHz | 4096 | 64 kB | 64 MB/s |
| 32768 | 37.5 kHz | 16384 | 256 kB | 256 MB/s |

#### **最初に確認すること: 614 MHz/ch で足りるか**

**SAM45 の広帯域モードは 1 台あたり 2 GHz 級**（要確認）で、**この構成の 1ch は 614 MHz** である。

fs は LMX の 491.52 MHz から**成立する動作点が 1228.8 MSPS 付近に限られる**（`VERSIONS.md`）。
**帯域を広げるならクロック構成から見直しになり、proj003〜008 の前提がまるごと動く。**
runbook が「**これが構成全体に最も波及する**」と書いている箇所そのもの。

**この確認を、他のどの設計判断よりも先に通すこと。**

### 2. 読み出し経路

runbook: 「積分後のスペクトルが小さければ BRAM + AXI-Lite で足りる。ダンプ間隔を詰める／
生データも見たいなら DMA、さらに深いバッファが要るなら PL 側 DDR4（4 GB / 64 bit）。
**PL DDR4 を使うかどうかは配置配線の難易度を大きく変えるので早めに。**」

proj003 以降は **AXI DMA** が既にあり、生データ取得に使っている。上の表の 8〜256 MB/s は
DMA の範囲に見えるが、**積分器の出力を DMA に載せるか BRAM に置くかは、ダンプ周期と
オーバーフローの扱いで変わる。**

## 着手条件

- **帯域・チャンネル数・積分時間の目標値が決まっていること。** 決まる前に RTL を書かない
  （runbook の警告どおり、ブロック構成が選べない）
- 614 MHz/ch で足りるかの確認が済んでいること
- proj008 の判定 6（一晩の持続性）が済んでいること。**時刻が数時間もつことを確かめないまま
  積分器を作ると、積分窓の設計が空中に浮く**

## 成功の判定

**目標値が決まってから確定する。** 現時点の骨格のみ:

| | 判定 |
|---|---|
| 1 | 既知の CW トーンが**期待するビンに、期待する電力で**立つ |
| 2 | 積分時間を変えてもノイズが √N で下がる（積分器が正しく積んでいる）|
| 3 | **オーバーフローが検出できる**（黙って飽和しない）|
| 4 | 積分窓の開始が `start_at` と一致する（proj007 の判定 3 の延長）|
| 5 | WNS ≥ 0 |

**判定 3 を外さないこと。** proj007 / proj008 で踏んだ穴はすべて「動いているように見える」
形だった。**飽和した積分器は、それらしいスペクトルを返す。**
