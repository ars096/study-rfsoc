# F-0 — 1PPS の取り込み（間隔・GLITCH）

- **前提**: 共通の前提。ボード直（root、specd を止めてから）。配線 N（入力は判定に効かない）
- **手順**:

```bash
python3 timetest.py --clkin 0 --ref 10 --t0 --seconds 30
```

- **合格**（測る前に決めた条件）:
  - 4 ADC のタイルの PLL がロック
  - TRIG・COMP の 2 系統とも、1PPS の間隔 − 1 秒が ±1 ビート以内
  - GLITCH・BAD・MISS 0
- **陽性対照**: なし（1PPS を抜いて MISS が立つことは確かめていない。立ったことのない MISS は「異常が無い」と「見張りが壊れている」を区別しない）
