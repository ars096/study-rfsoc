# F-2 — ADC → コアの遅れ（timebase.CAL の adc_to_core_ns）

- **前提**: 共通の前提。ボード直（root、specd を止めてから）。**配線 P**（1PPS を PPS Clk と ADC_A〜D に分配）。ケーブルを入れ替えて 2 回測る
- **手順**:

```bash
python3 timetest.py --clkin 0 --ref 10 --t2 --t2-adc 0,1,2,3 --out f2_a
# ADC のケーブルを A↔C・B↔D に入れ替えて
python3 timetest.py --clkin 0 --ref 10 --t2 --t2-adc 0,1,2,3 --out f2_b
```

- **合格**（測る前に決めた条件）:
  - 生サンプル（RAW の流れの SNAP のレコード）(a) で、4 ADC × 5 試行とも縁が見える（最大 / σ ≧ 20）
  - 1 回（1 つの Overlay）の中の σ ≦ 0.4 ビート、2 回の差 ≦ 1 ビート
  - M = 2 回の平均（ns）を timebase.CAL の (BIT_KIND, BIT_REV) の adc_to_core_ns に入れる。**同じ bit の測り直しなら CAL から ±2.5 ns 以内**（今の CAL: A 146.0・B 146.3・C 147.4・D 147.5 ns）。ビルドし直した bit（配置が違う）は新しく測った値を入れる
- **陽性対照**: 窓の生でない道 (b) では縁が見えない（山 / 中央値 ≒ 4）。縁の見張りが「何でも縁に見る」ものでないことの確かめ
