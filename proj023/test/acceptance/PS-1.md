# PS-1 — float32 の丸めと utc_ns の補正（INTERFACE 6.）

- **前提**: 共通の前提。specd（ボードで `python3 specd.py --clkin 0 --ref 10 --bits bits.json`、制御 PC から）。配線 N
- **手順**:

```bash
python3 s45v2c.py --host $B --n 50
```

- **合格**（測る前に決めた条件）:
  - 組 400・**不一致 0・最大 0.5 ulp**（float32 = u64 の最も近い丸め）・記録は版 2 だけ
  - CRC・説明のない欠け・kgap・tdev 0
  - 4 ADC × 2 窓とも束の間隔 40,960,000 ns ちょうど・e の幅 0.0 ns、**e(窓 0) − e(窓 1) = −1.1 ± 2 ns**
- **陽性対照**: 道具が補正（D(NS)・1.5·L(NS)）を足さずに比べると +746,697 ns ずれること
- **記録**: **最終の bit で通過（2026-10-14）**: 組 400・不一致 0・最大 0.5 ulp・版 2 だけ・4 ADC × 2 窓とも束の間隔 40,960,000 ns・e(窓 0) − e(窓 1) = −1.1 ns・補正なし +746,697 ns。2-2d の bit でも同じ（2026-10-13）
